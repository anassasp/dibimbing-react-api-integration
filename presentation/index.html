1. READ: Fetching Data

Let's populate our table using useQuery.


const fetchServices = async () => {
  const res = await fetch("http://localhost:3000/services");
  return res.json();
};

const { data, isLoading, isError } = useQuery({
  queryKey: ["services"],
  queryFn: fetchServices
});

React Query handles all the state automatically!

Quick Knowledge Check 🧠

Let's see if you're following!

Why do we use useQuery to fetch the table, but useMutation to submit the form?

Because Queries run automatically when the component loads.

But Mutations only run when the user explicitly triggers them (like clicking a submit button)!

2. CREATE & UI UPDATE

How to POST and refresh the table instantly.


const createMutation = useMutation({
  mutationFn: async (newService) => {
    await fetch("http://localhost:3000/services", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(newService)
    });
  },
  onSuccess: () => {
    // 💥 THE MAGIC TRICK 💥
    queryClient.invalidateQueries(["services"]);
  }
});

3. UPDATE: Saving Changes

Step 2: Send PUT request and invalidate.


const updateMutation = useMutation({
  mutationFn: async ({ id, updatedData }) => {
    await fetch(`http://localhost:3000/services/${id}`, {
      method: "PUT",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(updatedData)
    });
  },
  onSuccess: () => queryClient.invalidateQueries(["services"])
});

4. DELETE: Removing Data

Target the specific ID and destroy it.


const deleteMutation = useMutation({
  mutationFn: async (id) => {
    await fetch(`http://localhost:3000/services/${id}`, {
      method: "DELETE"
    });
  },
  onSuccess: () => queryClient.invalidateQueries(["services"])
});

Notice we don't need a body for DELETE requests!
